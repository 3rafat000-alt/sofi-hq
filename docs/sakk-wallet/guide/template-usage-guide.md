# دليل استخدام القوالب — صكّ المحفظة — صفحة لكل قالب

## قاعدة عامة — 90 ثانية
افتح Figma → اختر قالب → بدّل 3 حقول → صدّر PNG → انشر. كل حقل له حد أحرف.

## قالب 01: ميزة مربع 1080×1080 — feature
- **الهدف:** إعلان ميزة "ادفع في ثانيتين"
- **الحقول:** عنوان ≤6 كلمات (IBM Bold 32 #EAEAEA/#121212) — فرعي ≤18 كلمة 18sp 80% — زر ghost #00E676 — صورة 1:1 radius 16
- **مثال:** "ادفع في ثانيتين. بلا لمس." — "محفظة صكّ تحفظ بطاقاتك بتشفير كامل" — CTA "جرّب الدفع بلمسة"
- **حدود:** طويل 32 كلمة → يقلص إلى 16 ثم ... + تحذير "النص طويل — اختصره"
- **أخطاء:** لا تستخدم "مضمون 100%"

## قالب 02: عرض مربع — offer
- **هدف:** عرض خاص — سعر 0 مقابل 19
- **حقول:** عنوان 6 كلمات — فرعي 18 — سعر 42 Bold #121212 — قديم مشطوب 18
- **مثال:** "شهر مجاناً" — CTA "حمّل المحفظة الآن"

## قالب 03: شهادة مربع — quote
- **هدف:** اقتباس عميل — علامة 80px أخضر 20% — نجوم 20px — اسم 16sp "أحمد م." — **** 1234

## قالب 04: مقارنة مربع — compare
- **هدف:** قبل/مع صكّ — عمودين — "قبل" رمادي 60% — "مع" #00E676 + ✓ — صف 72px gap 16

## قالب 05: تنبيه مربع — alert
- **هدف:** تحديث — شريط داكن 48px أبيض 16sp — أيقونة 24px

## قالب 06: دعوة مربع — cta
- **هدف:** إحصائية 48 Bold #00E676 + وصف 16 — CTA "حمّل المحفظة الآن"

## قوالب 07-12: عمودي 1080×1350 — نفس الشبكة هوامش 40px
- نفس 6 أنواع مع تعديل هوامش — عنوان 32sp ثابت

## قوالب 13-18: ستوري/ريل 1080×1920 — منطقة آمنة 1080×1420 (250+250)
- غلاف: عنوان ثلث علوي آمن 36sp — شعار أسفل 48px
- lower third: blur16 — caption 180ms
- end card: CTA كبير

## أخطاء شائعة
- نص طويل يكسر الشبكة → اختصره إلى 18 كلمة
- صورة مفقودة → يظهر fallback #EAEAEA أيقونة 48px "أضف صورة 1080×1080"
- نص إنجليزي Wallet داخل عربي → RTL للفقرة LTR للكلمة دون كسر
