## القاعدة 3: التباين (Contrast) ≥4.5:1
| قبل | نص #888 على #EAEAEA — تباين 2.1:1 غير مقروء |
| بعد | #EAEAEA على #121212 = 15.2:1 — #121212 على #EAEAEA = 15.2:1 — #00E676 على #121212 = 12.1:1 |

| قاعدة | أساسي 4.5:1 — عناوين كبيرة 3:1 — لا معنى باللون وحده + أيقونة |
